# Start here

## At a glance

|---|---|

These blueprints show what it takes to run the OTel model family in production for telecom use cases. They use Red Hat products to show how the solution works. You can replace any component, and the blueprints make no product support claims. On this site, "OTel" means the OTel model family, not OpenTelemetry.
